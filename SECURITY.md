# Security

Please report vulnerabilities privately through GitHub: *Security → Report a vulnerability*
on this repository. Don't open a public issue for them.

Useful to include: what an attacker could do, how to reproduce it, and the Veil version
(*Settings → About*, or the release you installed).

Only the latest release gets fixes. Veil shows Instagram's own website; problems in Instagram
itself belong with Meta's bug bounty programme, not here.
